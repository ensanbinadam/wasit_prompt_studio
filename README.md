# وسيط | Wasit Prompt Studio (HTML + CSS + JS)

استوديو احترافي متكامل لهندسة وتوليد برومبتات الذكاء الاصطناعي وإنتاج منتجات رقمية نهائية مع توثيق مستقل وخيارات متقدمة.

---

## 🚀 محتويات المشروع وطرق التشغيل

### الطريقة الأولى: التشغيل المباشر السريع (بدون تثبيت أي برامج)
- افتح ملف `wasit-standalone.html` مباشرة بالنقر المزدوج في أي متصفح (Chrome, Edge, Safari, Firefox).
- يعمل دون حاجة لاتصال بالإنترنت أو خادم محلي.

### الطريقة الثانية: تشغيل المشروع الكامل مع خادم محلي ودعم الذكاء الاصطناعي (Gemini)
1. افتح موجه الأوامر (Terminal) في مجلد المشروع.
2. قم بتثبيت التبعيات:
   ```bash
   npm install
   ```
3. شغّل المشروع في وضع التطوير:
   ```bash
   npm run dev
   ```
4. افتح المتصفح على الرابط:
   ```
   http://localhost:3000
   ```

## 📁 هيكل الملفات
- `index.html`: الواجهة الرئيسية المبنية بـ HTML5 وعناصر التفاعل الدلالية.
- `wasit-standalone.html`: نسخة متكاملة ذاتية التشغيل في ملف واحد.
- `src/catalog.js`: مكتبة الـ 136 أمرًا، القوالب السريعة، الموجهات، ومواصفات المنتجات الرقمية.
- `src/promptBuilder.js`: محرك صياغة وتوليد البرومبت ومدقق الجودة.
- `src/app.js`: المتحكم الرئيسي وإدارة الحالة التفاعلية ومزامنة المتصفح.
- `src/index.css`: التنسيقات العصرية ودعم الوضعين الفاتح والداكن.
- `server.ts`: خادم Express مع تكامل نموذج Gemini 3.8 Flash لتجربة البرومبت الحية وتوسيع الأفكار.

## 🌟 أبرز المميزات
- 136 أمرًا احترافيًا مصنفًا في 9 مجالات.
- 11 قالبًا جاهزًا بنقرة واحدة.
- إعدادات ذكية متكيفة مع نوع المهمة (قصص مصورة، تعليم، برمجة، بحث، مرئيات).
- مكتبة مخصصة لشخصيات القصص (مثل شخصية سالم).
- طلب منتجات رقمية حقيقية قابلة للتنزيل (PDF, DOCX, PNG, HTML, PPTX, XLSX...).
- تذييل توثيق مستقل للمعلمين والباحثين مع محاكاة بصرية لموضعه.
- مدقق فوري لجودة البرومبت مع زر إصلاح فوري بنقرة واحدة.
- تجربة البرومبت مباشرة مع الذكاء الاصطناعي (Gemini 3.8 Flash).
- حفظ واستدعاء القوالب وتصدير واستيراد المكتبة بصيغة JSON.
